# task4
Dashboard Design using Tableau

 Objective:
To create an interactive sales dashboard using Tableau Public for business insights.

 Dataset:
- File: merch_sales.csv
- Data includes: sales, categories, dates, regions, quantities

Tools Used
- Tableau Public

 Dashboard Features
- KPIs: Total Sales, Shipping, Quantity
- Charts: Line chart (sales over time), bar chart (category sales), pie chart (region-wise), KPI cards
- Filters: Category, Date, Region
